features.py total functions

reset_stats() - resets the STATS dictionary which holds a bunch of useful values.
def _slope() - finds the slope of a signal
def _abs_integral() - finds the integral of abs value of a parameter.
def _peak_freq() - gives peak frequency and the index of the power
def _nan_block - to return a dict of keys and values as NaN.
def _decompose_eda - decomposes EDA signal into SCL and SCR. returns tonic
def _find_scrs - finds the skin response vlaues and returns (amplitudes, rise_times_s, durations_s)
def eda_features - gives the eda signal features.
def hr_features - gives hr features.
def imu_features - acc features.
def aggregate_short_windows - short windows for HR and for IMU data.
def cross_features - get motion artifacts out.
def feature_vector - gives a feature row with number organized.
def bvp_to_hr - derives hr from wesad, emulting my projects hardware.
